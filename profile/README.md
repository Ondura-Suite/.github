<h1 align="center">Ondura</h1>

<p align="center">
  An office suite for Windows, macOS and Linux – e-mail with calendar, contacts and tasks, word processing, spreadsheets and presentations.
</p>

<p align="center">
  <a href="https://ondura.mirranet.de"><b>ondura.mirranet.de</b></a> ·
  <a href="https://github.com/Ondura-Suite/Ondura-Core/releases/latest">Download</a> ·
  <a href="https://github.com/Ondura-Suite/Ondura-Core/issues">Report an issue</a>
</p>

<p align="center">
  <img src="https://raw.githubusercontent.com/Ondura-Suite/Ondura-Core/main/docs/screenshots/mail-light.png" width="820" alt="Ondura Mail">
</p>

Ondura looks and works like Microsoft 365, opens and saves Microsoft Office and LibreOffice files directly, and works with Microsoft 365, Exchange, IMAP, CalDAV/CardDAV, OneDrive and SharePoint. It speaks German, English and French.

| App | What it does |
| --- | --- |
| <img src="https://raw.githubusercontent.com/Ondura-Suite/Ondura-Core/main/apps/ondura/public/mail.svg" width="20"> **Ondura Mail** | E-mail, calendar, contacts and tasks in one window, like Outlook |
| <img src="https://raw.githubusercontent.com/Ondura-Suite/Ondura-Core/main/apps/ondura/public/text.svg" width="20"> **Ondura Text** | Word processor for `.docx` and `.odt` |
| <img src="https://raw.githubusercontent.com/Ondura-Suite/Ondura-Core/main/apps/ondura/public/sheets.svg" width="20"> **Ondura Sheets** | Spreadsheets for `.xlsx` and `.ods` |
| <img src="https://raw.githubusercontent.com/Ondura-Suite/Ondura-Core/main/apps/ondura/public/slides.svg" width="20"> **Ondura Slides** | Presentations for `.pptx` and `.odp` |

Installers for Windows 10/11, macOS 11 or later (`.dmg`) and Linux (`.deb`, `.rpm`, `.AppImage`) are on the [releases page](https://github.com/Ondura-Suite/Ondura-Core/releases). Ondura updates itself.
